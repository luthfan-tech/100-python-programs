# 100 Python Programs

I am building this repository as a daily Python practice journey. The focus is understanding logic, testing programs, and maintaining consistent GitHub progress.

## Purpose

- Strengthen programming fundamentals through daily practice.
- Build confidence with input/output, conditions, loops, strings, and basic algorithms.
- Create a public, honest record of my learning as a first-year CSE student.

## What’s Inside

- Small, focused Python programs (no copied solutions).
- Clear comments and sample I/O in each file.
- Progressive difficulty: from basic I/O to string manipulation and simple logic problems.

## Progress

- Programs completed: **40+** (as of Aug 15, 2026)
- Topics covered so far:
  - Input/Output, variables, type conversion
  - Conditions (`if/elif/else`)
  - Loops (`for`, `while`)
  - String methods and manipulation
  - Basic number logic and simple algorithms

## How to Use

- Each program is in its own file (e.g., `day-01.py`, `day-02.py`, …).
- Run with:
  ```bash
  python day-XX.py
  ```
- Read the comments and sample output in each file to understand the logic.

## Note

This is a learning repository, not a collection of perfect projects. The goal is consistent practice, honest progress, and gradual improvement.

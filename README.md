# 100 Python Programs

A personal Python-practice repository documenting my progress as a first-year B.Tech Computer Science and Engineering student.

The goal is not to upload 100 random solutions. It is to build programming logic through small, tested programs, understand every line of code, and maintain an honest record of consistent learning.

---

## 🎯 Purpose

This repository helps me:

- Strengthen core programming fundamentals through regular practice.
- Build confidence with Python syntax, logic, and debugging.
- Improve problem-solving through progressively harder exercises.
- Learn to turn a problem statement into a working program.
- Create a public, honest record of my learning journey.

---

## 📚 Topics Covered

The programs in this repository include practice with:

- Input, output, variables, and data types
- Type conversion
- Arithmetic, comparison, and logical operators
- Conditional statements: `if`, `elif`, and `else`
- Loops: `for` and `while`
- Strings, indexing, slicing, and string methods
- Numbers, patterns, and basic mathematical logic
- Lists, tuples, sets, and dictionaries
- Functions and code reusability
- Basic algorithms and problem-solving approaches
- Error handling and simple debugging

> Topics will be added gradually as I learn them. I will not claim a topic is completed unless I have practised it in code.
